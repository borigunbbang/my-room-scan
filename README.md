## 어디를 골랐나
- 책상, 모니터, 화장대, 책장이 있는 개인 침실입니다.
- **주의: 이번 과제가 요구하는 "밖에서 고른, 망설임 없이 공개 가능한 공간"에는 해당하지 않습니다.** 지나가는 사람 얼굴, 문패, 번호판 같은 특정 개인을 식별할 요소는 화면에 없다는 것은 확인했지만, 장소 자체가 사적 공간(자기 방)이라는 점에서 과제 취지와 어긋납니다. 이번 제출은 복원 → 형식 변환 → 뷰어로 이어지는 파이프라인이 정상 동작하는지 확인하기 위한 것이고, 실외 공용 공간 촬영은 별도로 다시 진행할 계획입니다.

**추가로 발견한 것**: `npx @playcanvas/splat-transform`이 기본으로 만드는 `.spz`는 버전 4(비압축 `NGSP` 헤더)인데, 이 뷰어가 쓰는 Spark 2.2.0은 아직 버전 4를 못 읽습니다(`Unsupported SPZ version: 4`). `--spz-version 3`을 붙이면 예전 방식(gzip으로 감싼)으로 나와서 정상적으로 뜹니다. 위 표의 `.spz` 크기는 기본값(버전 4) 기준이고, 실제 뷰어 테스트는 버전 3(21.92MB)으로 했습니다.
